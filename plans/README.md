**Agy 001 build note**: live verification (Phase 16, 2026-09-06) found the
source review's proposed fix — map every `PreInvocation` to
`UserPromptSubmit` — would have been wrong: `PreInvocation` fires multiple
times per top-level turn (once per intra-turn tool-call round-trip), not
once per turn. The actual fix maps only `invocationNum == 0` (confirmed live
to reliably reset at the start of every new turn, even resumed ones in the
same process) — see `Antigravity_Implementation_Plans.md`'s Plan 001 and
CLAUDE.md's Phase 16 entry. Agy 003, when scheduled, should reuse this same
`invocationNum == 0` signal for its own first-turn detection rather than the
plan's originally-drafted `invocationNum == 1` assumption.

## Findings considered and rejected

- Full Codex decision extraction is deferred. Current Codex hook payloads expose
  prompt and last-assistant-message fields, but implementing reliable turn
  pairing is a separate product feature rather than a prerequisite for stable
  lifecycle integration.
- Codex failure-state inference from tool output is deferred. Current Codex
  PostToolUse does not provide a stable failure discriminator; the app should
  not add text heuristics until that upstream contract is stable.
- Full Antigravity decision extraction (`USER_INPUT`/`PLANNER_RESPONSE`
  transcript parsing) is deferred for the same reason, and would need a
  deliberate widening of `is_claude_transcript_path`'s Phase 10 leak-fix
  gate rather than a drive-by change.
- Antigravity `run_command` failure inference from model prose or transcript
  content is rejected outright (invariant #5), not merely deferred — already
  pinned as a known upstream limit by a named unit test in `antigravity.rs`.
- `agy -p` as an extractor backend is deferred — unconfirmed that Antigravity
  supports a non-interactive text-output mode analogous to `claude -p`.

See `Antigravity_Implementation_Plans.md`'s header note for why Agy 001 and
004 carry a HIGH risk rating the Codex plans don't: they touch a
synchronous, blocking-capable hook class Phase 11 deliberately excluded.
